## Escolhi o tema de catálogo de receitas.

## Como usar/Descrição

1. O site tem 3 abas: Inicio, Gerenciar e Sobre.
2. Vá para Gerenciar para criar novas receitas. (Todos os campos precisam ser preenchidos).
3. As receitas aparecem na página de Início.
4. Use os botões de editar/excluir nos cards para modificar ou remover receitas.
5. O conteúdo é salvo no localStorage do navegador e os dados ficam no seu computador.
6. Você também pode testar o filtro disponivel em "Buscar Receitas".
7. A página sobre só tem algumas informações sobre o site. (basicamente o mesmo que está aqui).

## Como rodar localmente

1. `npm install`
2. `npm run dev`
3. Abrir http://localhost:5173
